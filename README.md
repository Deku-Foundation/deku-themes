# Deku Themes and Visual Identity

Open desktop theme assets and visual integration for Deku Linux.

## Status

Bootstrap stage. Assets and packaging are not a supported release yet.

## Responsibilities

- Maintain theme source files, icons, wallpapers and desktop appearance configuration with clear licenses.
- Prefer accessible contrast, consistent light/dark variants and upstream-compatible formats.
- Record attribution and license for every imported asset.
- Keep branding assets separate from system-critical packages.

## Non-goals

This repository does not build the desktop stack or define the operating system architecture. Avoid redistributing assets without verified rights.
